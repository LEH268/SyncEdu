Chapter 2 — Number Bases

2.1 Place value and the idea of a base

Our everyday numbers are written in base ten: there are ten digits, 0 to 9, and each column is worth ten times the column to its right. A base (or radix) b uses b digits, from 0 up to b − 1, and each column is worth b times the one to its right. The digits available in base b are therefore 0, 1, …, b − 1; a digit equal to or larger than the base can never appear. So 2, 5 and 7 are all legal in base 8, but 8 and 9 are not.

A subscript names the base: 101₂ is a base-two number, 101₁₀ a base-ten number. In Form 4 we work mainly with bases 2, 5, 8 and 10.

2.2 Converting from base b to base ten

Expand the number using place values and add up in base ten. Multiply each digit by the base raised to the power of its column position, counting from 0 at the right.

Example 1. Convert 1101₂ to base ten.

1·8 + 1·4 + 0·2 + 1·1 = 8 + 4 + 0 + 1 = 13₁₀.

Example 2. Convert 324₅ to base ten.

3·25 + 2·5 + 4·1 = 75 + 10 + 4 = 89₁₀.

2.3 Converting from base ten to base b

Use repeated division by the base. Divide the number by b, record the remainder, then divide the quotient again, until the quotient is 0. The answer is the string of remainders read from bottom to top.

Example 3. Convert 45₁₀ to base 2.

45 ÷ 2 = 22 r 1; 22 ÷ 2 = 11 r 0; 11 ÷ 2 = 5 r 1; 5 ÷ 2 = 2 r 1; 2 ÷ 2 = 1 r 0; 1 ÷ 2 = 0 r 1.

Reading upward: 45₁₀ = 101101₂.

Always check by converting back: 32 + 8 + 4 + 1 = 45.

2.4 Converting between two non-ten bases

There is no direct shortcut in general: convert to base ten as a bridge, then convert base ten to the target base.

Example 4. Convert 234₅ to base 8.

234₅ = 2·25 + 3·5 + 4 = 69₁₀.

69 ÷ 8 = 8 r 5; 8 ÷ 8 = 1 r 0; 1 ÷ 8 = 0 r 1, so 69₁₀ = 105₈.

2.5 The special link between base 2 and base 8

Because 8 = 2³, each base-8 digit corresponds to exactly three base-2 digits. To go from binary to octal, group the binary digits in threes from the right and replace each group by its value. To go the other way, expand each octal digit into three binary digits.

Example 5. Convert 11010110₂ to base 8.

Group from the right: 11 | 010 | 110 → 011 | 010 | 110 = 3, 2, 6.

So 11010110₂ = 326₈.

2.6 Adding and subtracting in a base

Column arithmetic works exactly as in base ten, but you carry or borrow the base instead of ten. In base 5, when a column total reaches 5 you write down the total minus 5 and carry 1. When subtracting, a borrow brings across 5, not 10.

Example 6. Work out 34₅ + 23₅.

Units: 4 + 3 = 7 = 5 + 2, write 2 carry 1. Fives: 3 + 2 + 1 = 6 = 5 + 1, write 1 carry 1. Answer: 112₅.

Check in base ten: 19 + 13 = 32, and 112₅ = 25 + 5 + 2 = 32. ✓

2.7 Number sequences and computed digits in a base

You may be asked to continue a pattern written in another base, or to find a missing digit. Convert to base ten, reason about the pattern or equation there, then convert the result back. For a missing-digit problem such as "x4₅ = 24₁₀", expand: 5x + 4 = 24, so x = 4.

2.8 Multiplying and dividing in a base

Multiplication by the base itself just shifts every digit one column to the left and writes a zero in the units place, exactly as multiplying by ten does in base ten. So 23₅ × 5₅ = 230₅. For a general product it is usually safest to convert to base ten, multiply, and convert back.

Example 7. Work out 12₂ × 11₂.

12₂ = 6₁₀, 11₂ = 3₁₀; 6 × 3 = 18.

18 ÷ 2 repeatedly gives remainders 0,1,0,0,1, so the answer is 10010₂.

2.9 Common errors to avoid

Three mistakes appear again and again. First, using a digit that is too big for the base — writing a 5 in a base-5 number, which is never allowed. Second, reading the repeated-division remainders top to bottom instead of bottom to top. Third, forgetting to carry the base rather than ten when adding. A quick base-ten check at the end catches all three: convert your answer back and see that it matches.

2.10 Why bases matter

Computers store everything in base 2 because a switch has two states, and programmers use base 8 and base 16 as compact shorthand for long binary strings. A single kilobyte is 2¹⁰ bytes precisely because the hardware counts in powers of two. Understanding place value in any base also deepens understanding of the base-ten algorithms learned in primary school, which are simply the b = 10 case of these same rules, and it makes the idea of "carrying" and "borrowing" concrete rather than a memorised trick.
