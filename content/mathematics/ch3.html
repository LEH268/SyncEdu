Chapter 3 — Logical Reasoning

3.1 Statements

A statement is a sentence that is either true or false, but not both. "9 is a multiple of 3" is a true statement; "A triangle has four sides" is a false statement. Questions, commands and opinions are not statements because no truth value can be assigned. The truth value of a statement is simply whether it is true (T) or false (F).

3.2 Negation

The negation of a statement p, written ¬p or "not p", reverses its truth value. If p is true then ¬p is false, and vice versa. Negation is often formed by inserting or removing "not", but care is needed with quantifiers: the negation of "all prime numbers are odd" is "some prime numbers are not odd", not "no prime numbers are odd".

3.3 Compound statements: "and" and "or"

Two statements can be joined by and (conjunction) or or (disjunction). "p and q" is true only when both parts are true. "p or q" is true when at least one part is true, and false only when both parts are false — this is the inclusive "or" used throughout mathematics.

3.4 Implication: "if… then…"

An implication "if p, then q" is written p → q. Here p is the antecedent and q the consequent. An implication is false only in the single case where p is true but q is false; in every other case it is treated as true.

From p → q we can build three related statements:

Name Form
Converse q → p
Inverse ¬p → ¬q
Contrapositive ¬q → ¬p

The contrapositive always has the same truth value as the original; the converse and inverse need not.

Example 1. "If a number is divisible by 6, then it is divisible by 3." The contrapositive is "If a number is not divisible by 3, then it is not divisible by 6" — also true. The converse, "If a number is divisible by 3, then it is divisible by 6", is false (9 is a counterexample).

3.5 Biconditional: "if and only if"

"p if and only if q", written p ↔ q, means both p → q and q → p hold. It is true when p and q have the same truth value and false otherwise.

3.6 Arguments, premises and conclusions

An argument is a set of statements called premises offered as support for a further statement called the conclusion. An argument is valid when the conclusion must be true whenever all the premises are true, regardless of whether the premises actually are true.

Two standard valid forms are worth memorising:

Modus ponens: p → q ; p ; ∴ q

Modus tollens: p → q ; ¬q ; ∴ ¬p

Example 2. Premises: "If it rains, the field is wet." "The field is not wet." By modus tollens the conclusion is "It did not rain." The argument is valid.

Two common invalid patterns are the fallacy of affirming the consequent (p → q; q; ∴ p) and denying the antecedent (p → q; ¬p; ∴ ¬q).

3.7 Deductive and inductive reasoning

Deductive reasoning moves from general rules to a specific case and, when valid, guarantees the conclusion. Inductive reasoning moves from specific observations to a general rule; it makes the conclusion likely but not certain, and a single counterexample overturns it. Recognising which kind of reasoning a passage uses is a frequent exam question.

Example 3. "1, 4, 9, 16 are perfect squares, so the next term is 25" is inductive. "Every square is non-negative, and 7² is a square, so 7² ≥ 0" is deductive.

3.8 Using truth tables to test equivalence

Two compound statements are logically equivalent if they have identical final columns in a truth table. Building the table row by row — one row for each combination of truth values of the basic statements — is the reliable way to settle claims such as "¬(p and q) is equivalent to (¬p or ¬q)", one of De Morgan's laws. A statement that is true in every row is a tautology; one that is false in every row is a contradiction.

Example 4. Show that p → q is equivalent to ¬p or q. In the row p = T, q = F the implication is F and (¬p or q) is (F or F) = F; in every other row both are T. The columns match, so the two are equivalent.

3.9 Reasoning by counterexample

To disprove a general claim of the form "for all x, P(x)" it is enough to produce a single counterexample — one value of x that makes P(x) false. To disprove an existence claim "for some x, P(x)" you must show P fails for every x. This asymmetry is why one exception overturns an inductive generalisation but never a valid deduction.

Example 5. Claim: "every odd number is prime." The value 9 is odd but not prime, so the claim is false — one counterexample suffices.

3.10 Building and analysing arguments in context

Given a short passage, the exam skill is to identify the premises and the conclusion, restate the argument in symbolic form, name the pattern (modus ponens, modus tollens, or a named fallacy), and state whether it is valid. A valid argument with a false premise can still have a false conclusion; only a sound argument — valid and with all premises true — guarantees a true conclusion.
