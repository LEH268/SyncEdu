Chapter 4 — Operations on Sets

4.1 Sets and notation

A set is a well-defined collection of distinct objects called elements. "Well-defined" means there is a clear rule for deciding whether any given object belongs. We write a ∈ A to say a is an element of A, and a ∉ A otherwise. Sets can be listed, as {2, 3, 5, 7}, or described by a property, as {x : x is a prime number less than 10}. The number of elements in a set A is written n(A). The empty set ∅ has no elements, so n(∅) = 0.

4.2 Subsets and the universal set

A is a subset of B, written A ⊆ B, if every element of A is also an element of B. The empty set is a subset of every set, and every set is a subset of itself. A set with n elements has exactly 2n subsets. The universal set ξ contains every element under discussion for a particular problem; all other sets are drawn inside it on a Venn diagram.

4.3 Complement

The complement of A, written A′, is the set of elements of the universal set that are not in A.

A′ = { x : x ∈ ξ and x ∉ A }

It follows that n(A) + n(A′) = n(ξ), and that (A′)′ = A.

4.4 Intersection

The intersection A ∩ B is the set of elements common to both A and B. If A ∩ B = ∅ the sets are disjoint. Intersection corresponds to the logical word "and".

Example 1. A = {1, 2, 3, 4, 6}, B = {2, 4, 6, 8}. A ∩ B = {2, 4, 6}.

4.5 Union

The union A ∪ B is the set of elements in A or in B or in both. Each element is listed once even if it belongs to both sets. Union corresponds to the logical word "or".

Example 2. With the sets above, A ∪ B = {1, 2, 3, 4, 6, 8}.

4.6 Combining operations

Expressions such as (A ∪ B)′ or A ∩ (B ∪ C) are evaluated from the innermost bracket outward, just like arithmetic. Shading a Venn diagram region by region is the safest method. Two identities, De Morgan's laws, are used often:

(A ∪ B)′ = A′ ∩ B′

(A ∩ B)′ = A′ ∪ B′

Example 3. ξ = {1,…,10}, A = {2,4,6,8,10}, B = {1,2,3,4,5}. Then A ∪ B = {1,2,3,4,5,6,8,10}, so (A ∪ B)′ = {7, 9}. Checking: A′ = {1,3,5,7,9}, B′ = {6,7,8,9,10}, and A′ ∩ B′ = {7, 9}. ✓

4.7 The addition rule for two sets

To count the elements of a union without double-counting the overlap:

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

Example 4. In a class of 30, 18 study Biology and 15 study Chemistry; 7 study both. How many study at least one?

n(B ∪ C) = 18 + 15 − 7 = 26. So 26 students study at least one, and 30 − 26 = 4 study neither.

4.8 Three-set problems with Venn diagrams

For three overlapping sets, fill the diagram from the centre outward: place n(A ∩ B ∩ C) first, then subtract to find each pairwise-only region, then each single-set-only region, then the outside. Every unknown is found by making a region total match the information given. Let the required quantity be x, express each region in terms of x, and form an equation from the grand total.

Example 5. Of 40 tourists, 20 visited Penang, 18 Melaka, 16 Langkawi; 8 visited Penang and Melaka, 6 Melaka and Langkawi, 7 Penang and Langkawi, and 3 visited all three. How many visited none?

By inclusion–exclusion: 20 + 18 + 16 − 8 − 6 − 7 + 3 = 36 visited at least one, so 40 − 36 = 4 visited none.

4.9 Describing shaded regions

The reverse of shading is reading: given a Venn diagram with a region shaded, write it in set notation. Work from what the region includes and excludes. A region inside A and inside B but outside C is A ∩ B ∩ C′. The region in exactly one of two sets is (A ∪ B) ∩ (A ∩ B)′, sometimes called the symmetric difference. Practising both directions — notation to shading and shading to notation — is essential because either can be asked.

Example 6. The shaded region lies inside A or inside B but not in both. In notation this is (A ∪ B) ∩ (A ∩ B)′, or equivalently (A ∩ B′) ∪ (A′ ∩ B).

4.10 Why set language matters

Sets give a precise vocabulary for classification, probability (where events are sets of outcomes) and database queries (where "and", "or" and "not" filter records). The Venn-diagram habit of accounting for every region without overlap is the same discipline used in survey analysis and in checking that cases in a proof are exhaustive. When you later study probability, P(A ∪ B) = P(A) + P(B) − P(A ∩ B) is exactly the addition rule of section 4.7 with counts replaced by probabilities.
