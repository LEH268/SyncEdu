Chapter 1 — Quadratic Functions and Equations

1.1 What is a quadratic equation?

A quadratic equation in one variable is any equation that can be written in the general form below, where a, b and c are constants and a ≠ 0. If a were zero the highest power of x would be 1, and the equation would be linear. The name comes from quadratus, Latin for "square", because the defining feature is the x² term.

ax² + bx + c = 0, a ≠ 0

A value of x that makes the equation true is called a root or solution. A quadratic equation has at most two real roots. Checking a candidate root is always done by substitution: put the value back into the left-hand side and confirm it evaluates to zero.

1.2 Solving by factorisation

When the quadratic expression factorises over the integers, factorisation is the fastest method. We rewrite the expression as a product of two brackets and use the zero-product property: if two numbers multiply to give zero, at least one of them must be zero. For ax² + bx + c with a = 1, we look for two integers whose product is c and whose sum is b.

Example 1. Solve x² + 5x + 6 = 0.

We need two numbers that multiply to 6 and add to 5: these are 2 and 3.

So (x + 2)(x + 3) = 0, giving x = −2 or x = −3.

When a ≠ 1, we split the middle term: find two numbers whose product is ac and whose sum is b, use them to break bx into two terms, then factorise in pairs.

Example 2. Solve 3x² + 10x + 8 = 0.

ac = 24 and b = 10, so use 6 and 4: 3x² + 6x + 4x + 8 = 0.

3x(x + 2) + 4(x + 2) = 0, so (3x + 4)(x + 2) = 0.

x = −4/3 or x = −2.

1.3 Completing the square

Not every quadratic factorises neatly. Completing the square rewrites the expression so the variable appears only once, which also reveals the turning point of the graph. The key identity is:

x² + bx = (x + b/2)² − (b/2)²

Example 3. Solve x² − 6x + 4 = 0 by completing the square.

x² − 6x = (x − 3)² − 9, so (x − 3)² − 9 + 4 = 0.

(x − 3)² = 5, so x − 3 = ±√5 and x = 3 ± √5.

If the coefficient of x² is not 1, divide every term by a first, then complete the square on the result.

1.4 The quadratic formula

Completing the square on the general form gives a formula that solves every quadratic equation, whether or not it factorises.

x = ( −b ± √(b² − 4ac) ) / 2a

The method is mechanical: identify a, b and c with their signs, substitute, simplify the discriminant first, then finish. Careless sign errors on b when b is negative are the most common mistake.

1.5 The discriminant

The expression under the square root, b² − 4ac, is called the discriminant, often written Δ. It tells us how many real roots exist before we finish solving, and whether the roots are rational.

Discriminant Number of real roots Graph
b² − 4ac > 0 Two distinct roots Crosses the x-axis twice
b² − 4ac = 0 One repeated root Touches the x-axis once
b² − 4ac < 0 No real roots Does not meet the x-axis

A common exam task is the reverse problem: given that an equation has equal roots, set Δ = 0 and solve for the unknown constant.

Example 4. Find k if x² + kx + 9 = 0 has equal roots.

Δ = k² − 36 = 0, so k² = 36 and k = ±6.

1.6 The shape of the graph

The graph of y = ax² + bx + c is a parabola. It opens upwards when a > 0 and downwards when a < 0. The axis of symmetry is x = −b/2a, and the turning point (vertex) lies on it — a minimum when the parabola opens upwards, a maximum when it opens downwards. The y-intercept is always c. The x-intercepts, if any, are the roots of the matching equation.

Writing the function in completed-square form y = a(x − h)² + k gives the vertex directly as (h, k), and k is the maximum or minimum value of y.

Example 5. Solve 2x² − 7x + 3 = 0 using the formula, and state the vertex.

a = 2, b = −7, c = 3. The discriminant is 49 − 24 = 25, so there are two roots.

x = (7 ± 5) / 4, giving x = 3 or x = 0.5.

Axis of symmetry x = 7/4; substituting gives y = −25/8, so the vertex is (1.75, −3.125), a minimum.

1.7 Forming a quadratic from its roots

If the roots are α and β, then the equation can be written as

x² − (α + β)x + αβ = 0

So the sum of roots is −b/a and the product of roots is c/a. This lets us build an equation with required roots, or check a solution without re-solving.

Example 6. Form the equation whose roots are 4 and −1.

Sum = 3, product = −4, so x² − 3x − 4 = 0.

1.8 Word problems

Many practical situations — area, projectile height, consecutive numbers — lead to a quadratic. The routine is: define the variable, translate the sentence into an equation, solve, then reject any root that is impossible in context (a negative length, for example) and state the answer in words.

Example 7. A rectangular garden is 3 m longer than it is wide and has an area of 40 m². Find its width.

Let the width be w. Then w(w + 3) = 40, so w² + 3w − 40 = 0.

(w + 8)(w − 5) = 0, so w = −8 or w = 5. A width cannot be negative, so w = 5 m.

1.9 Choosing a method

With practice the choice becomes quick. Try factorisation first; if the numbers do not come out in a few seconds, check the discriminant. If b² − 4ac is a perfect square the equation still factorises, so persevere; if it is not, use the formula. Completing the square is preferred when the question also asks for the turning point, the maximum or minimum value, or the range of the function. When the equation has a common factor, divide it out first: 2x² − 8x + 6 = 0 becomes x² − 4x + 3 = 0, which factorises at once to give x = 1 or x = 3. Always finish by substituting both roots back into the original equation as a check.

1.10 Quadratic inequalities

To solve ax² + bx + c > 0, first find the roots, then use the shape of the parabola. If a > 0 the expression is positive outside the roots and negative between them; if a < 0 it is the other way round. Sketching the parabola and reading off where it lies above or below the x-axis is more reliable than memorising rules.

Example 8. Solve x² − x − 6 ≤ 0.

Roots: (x − 3)(x + 2) = 0, so x = 3 or x = −2. Since a > 0 the curve is below the axis between the roots, so the solution is −2 ≤ x ≤ 3.
