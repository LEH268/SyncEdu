Chapter 5 — Network in Graph Theory

5.1 What is a network?

A graph (or network) is a diagram of points, called vertices (or nodes), joined by lines, called edges. It records only which vertices are connected, not distance or direction of drawing, so the same graph can be drawn in many shapes. Graphs model road maps, water pipes, friendships, and computer networks. We write V for the number of vertices and E for the number of edges.

5.2 Degree of a vertex

The degree of a vertex is the number of edges meeting it. A loop (an edge from a vertex to itself) counts as 2. Adding the degrees of every vertex counts each edge twice, which gives the handshake lemma:

∑ degree(v) = 2E

A consequence is that the number of vertices of odd degree is always even.

Example 1. A graph has degrees 3, 3, 2, 2, 2. The sum is 12, so E = 6. There are two odd-degree vertices, which is consistent.

5.3 Types of graph

Term Meaning
Simple graph No loops and no repeated edges between the same pair
Directed graph Each edge has an arrow giving a one-way connection
Weighted graph Each edge carries a number: distance, cost or time
Complete graph Every pair of vertices is joined by an edge
Subgraph A graph formed from some of the vertices and edges of a larger graph

A complete graph on n vertices has n(n − 1)/2 edges.

5.4 Walks, paths and cycles

A walk is any sequence of edges followed end to end. A path is a walk that repeats no vertex. A cycle is a path that returns to its start. A graph is connected if there is a path between every pair of vertices; otherwise it splits into components.

5.5 Trees

A tree is a connected graph with no cycles. Every tree on n vertices has exactly n − 1 edges, and adding any new edge creates exactly one cycle while removing any edge disconnects it. A spanning tree of a connected graph is a subgraph that is a tree and includes every vertex.

5.6 The minimum spanning tree

In a weighted connected graph, the minimum spanning tree is the spanning tree whose total edge weight is smallest — the cheapest way to link every vertex. It is found by a greedy method. Using Kruskal's algorithm: list the edges in increasing weight, and add each edge in turn unless it would form a cycle, stopping when n − 1 edges have been chosen.

Example 2. Five towns with connecting road costs (RM thousands): AB 4, AC 3, BC 2, BD 5, CD 6, CE 7, DE 3. Sorted: BC 2, AC 3, DE 3, AB 4, BD 5, … Take BC (2), AC (3), DE (3), then AB (4) would connect A which is already linked via C — check: A–C–B, adding AB makes a cycle, reject. Take BD (5): now {A,B,C,D} joined and E joined via D. Edges BC, AC, DE, BD — four edges for five towns. Total cost RM 13 000.

5.7 The shortest path

The shortest-path problem asks for the route of least total weight between two named vertices, which is not the same as the minimum spanning tree. Dijkstra's algorithm keeps a working value for each vertex — the shortest distance found so far from the start — repeatedly picks the unvisited vertex with the smallest working value, marks it permanent, and updates its neighbours.

Example 3. From the graph in Example 2, the shortest path from A to E: A–C is 3, C–B is 2 (A to B via C = 5), B–D is 5 (A to D = 10), D–E is 3 (A to E = 13). Compare A–C–E directly = 3 + 7 = 10. The shortest A–E route is A–C–E at cost 10.

5.8 Eulerian and Hamiltonian journeys

An Eulerian trail uses every edge exactly once; it exists precisely when the graph is connected and has zero or two odd-degree vertices (with two, the trail must start and end at those). A Hamiltonian path visits every vertex exactly once; there is no simple degree test for it. Distinguishing "every edge" from "every vertex" is the key to choosing the right tool in routing problems such as postal delivery (edges) versus a sales tour (vertices).

5.9 Reading and drawing networks

Given a table of connections, draw the vertices first, spaced out, then add each edge and label its weight. Given a drawn network, a common task is to complete an adjacency table: a grid whose entry in row i, column j is the number of edges directly joining vertex i to vertex j. The row totals of an adjacency table are the vertex degrees, and for a graph with no directions the table is symmetric about its leading diagonal.

5.10 Traversability

A network is traversable if it can be drawn in one continuous stroke without lifting the pen and without going over any edge twice — exactly the Eulerian-trail condition of section 5.8. Count the odd-degree vertices: zero means a closed trail is possible from any start; two means an open trail from one odd vertex to the other; four or more means it cannot be done in a single stroke. This is the mathematics behind the classic "Bridges of Königsberg" problem, which has four odd vertices and so no solution.

Example 4. A floor plan has rooms as vertices and doorways as edges, with degrees 2, 2, 3, 3. Two odd vertices, so a guard can walk through every doorway exactly once, but must start in one odd-degree room and finish in the other.

5.11 Choosing the right technique

Routing questions turn on one distinction. "Visit every place" is a Hamiltonian problem (a sales tour). "Travel along every road" is an Eulerian problem (gritting or mail delivery). "Connect every place as cheaply as possible" is a minimum spanning tree (laying cable). "Get from here to there fastest" is a shortest path. Reading the question to identify which of the four it is, before doing any calculation, is the single most valuable habit in this chapter.
